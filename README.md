# avocat_plus

Site demonstrativ pentru alegerea și programarea unui avocat: domenii de practică, profiluri cu istoric și arhivă de cazuri, comparare, tarife în MDL și programare online.

Este un site static (un singur fișier `index.html`), fără server. Avocații, cazurile și recenziile sunt fictive.

## Publicare pe Vercel
1. Importă acest repository pe https://vercel.com/new
2. Framework Preset: **Other**. Nu e nevoie de build command.
3. Apasă **Deploy**.
